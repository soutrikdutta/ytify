# Ytify 🎵
A High-Fidelity Music Streaming Experience powered by YouTube & Dolby Atmos Spatial Audio.

Developed by **Soutrik**.

## Features
- **Dolby Atmos & Spatial Audio Simulator**: Cinematic acoustic enhancement.
- **YouTube Powered Streaming**: Search and stream any song instantly with Google Autocomplete.
- **Responsive Layout**: Specially tailored experience for mobile and desktop/PC screens.
- **Cross-Platform**: Web App & Android APK.
- **Guest & Google Login**: Instant playback without mandatory onboarding.
